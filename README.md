# Vibe Coding Course

Курс о том, как работать с AI в разработке — на примере реального
production-проекта (grid trading bot).

## Структура

**Блок 1: Фундамент**
1. Что такое vibe coding (и чем это не «AI напишет за меня»)
2. Почему AI без контекста — это джун без онбординга
3. Цикл vibe coding: задача → план → код → тест → правила

**Блок 2: Инструменты диалога**
4. CLAUDE.md: как объяснить AI правила твоего проекта
5. RULES.md: код-стайл и доменные грабли как часть промпта
6. Как формулировать задачу для AI

**Блок 3: Дисциплина**
7. Почему тесты в AI-разработке важнее, чем в обычной
8. План перед кодом
9. Когда AI врёт уверенно: как ловить галлюцинации
10. Один разговор = одна задача: гигиена сессий
